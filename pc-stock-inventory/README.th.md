# ระบบจัดสรรสินค้าคอมพิวเตอร์ (ภาษา C)

โปรแกรมคอนโซลสำหรับจัดการสต็อกอุปกรณ์คอมพิวเตอร์ แยกสินค้าเป็นหมวด
และแจ้งเตือนเมื่อสินค้า **ใกล้หมด** หรือ **หมดสต็อก**

[English](README.md)

## ความสามารถ

- 8 หมวด: CPU, Motherboard, RAM, GPU, Storage, Power Supply, Monitor, Accessories
- แจ้งเตือนใกล้หมดเมื่อ `qty <= min` (แต่ละสินค้าตั้งจุดเตือนเองได้)
- แจ้งเตือนสินค้าหมดเมื่อ `qty == 0`
- แสดงการแจ้งเตือนตอนเปิดโปรแกรม และหลังรับเข้า/จ่ายออกที่ทำให้สถานะเปลี่ยน
- รับเข้า จ่ายออก (จ่ายเกินจำนวนที่มีไม่ได้) เพิ่ม ลบ และแก้จุดเตือน
- บันทึกข้อมูลลงไฟล์ `stock.txt` อัตโนมัติ
- ไม่ต้องติดตั้งไลบรารีเพิ่ม (C99)

## คอมไพล์และรัน

```bash
make
./pc_stock
```

หรือใช้ gcc โดยตรง:

```bash
gcc -std=c99 -Wall -Wextra -o pc_stock src/pc_stock.c
```

ครั้งแรกโปรแกรมจะสร้างสินค้าตัวอย่าง 10 รายการใน `stock.txt`

## เอกสาร

ดู [docs/code-guide-th.pdf](docs/code-guide-th.pdf) สำหรับการวิเคราะห์งาน ผังงาน และคำอธิบายโค้ดทั้งหมด

## ข้อจำกัด

- สินค้าได้สูงสุด 200 รายการ (`MAX_ITEMS`)
- ชื่อสินค้าห้ามมีเครื่องหมาย `|`
